# 데일리빈 (Daily Bean)

날씨와 우리 매장 추출 기록으로 그라인더 분쇄도를 추천하고, 재고·매출·고객 포인트까지 한 곳에서 관리하는 카페 매니저용 웹서비스입니다.

스크립트 프로그래밍 과제 (생성형 AI 바이브 코딩 React 웹서비스).

## 주요 기능
1. 날씨(Open-Meteo) + 원두 숙성일 + 샷 기록 기반 분쇄도 추천
2. 샷 기록 (등록·수정·삭제·검색)
3. 품목 관리 (등록·수정·삭제·검색)
4. 재고 입고·마감 실사 → 사용량 계산, 부족 알림
5. 매출 (카드·현금, 일/주/월 그래프)
6. 고객 포인트 (누적 45,000원마다 무료 음료 쿠폰)
7. 대시보드: 오늘 날씨·추천 분쇄도·조정 알림, 최근 샷(교대 인수인계), 부족 재고, 매출 요약
8. 설정: 매장 위치 검색, 분쇄도 기준값·계수, 쿠폰 기준, 백업 내보내기/불러오기

## 분쇄도 추천식
```
추천 = 기준값 − a×(습도−기준습도)/10 − b×(기온−기준기온)/10 + 숙성 보정 + 최근 샷 보정
```
기본값: 기준 6.5 (라마르조꼬, 높을수록 가늘게), 습도 60%, 기온 20℃, a=0.2, b=0.1, 로스팅 3일 이내 −0.1, 결과는 6.0~7.0.
최근 샷 보정은 최근 10개 샷의 (실제 분쇄도 − 당시 날씨 기반 추천값) 평균 (±0.3 제한)이라, 기록이 쌓일수록 매장에 맞춰져요.

## 페이지
| 경로 | 페이지 |
|---|---|
| `/` | 대시보드 |
| `/grind` | 분쇄도 추천 + 샷 기록 |
| `/stock` | 재고 입고·마감 실사 |
| `/items` | 품목 |
| `/sales` | 매출 |
| `/customers` | 고객 포인트 |
| `/settings` | 설정 |

## 기술
React 19, Vite, React Router, Context + useReducer, localStorage, Recharts, Open-Meteo API (키 없음)
