# 데일리빈 (Daily Bean)

카페의 하루 흐름(오픈 → 영업 → 마감 → 발주)을 한 곳에서 관리하는 카페 운영 관리 웹서비스입니다. 체크리스트·인수인계, 재고·발주, 매출, 고객 쿠폰을 다루고, 날씨와 매장 샷 기록으로 분쇄도를 추천합니다.

배포 주소: https://dailybean.vercel.app

스크립트 프로그래밍 과제 (생성형 AI 바이브 코딩 React 웹서비스).

## 주요 기능
1. 매장 운영: 오픈·마감 체크리스트(누가 몇 시에 했는지 기록), 인수인계 메모, 지금 근무자 선택
2. 재고·발주: 품목 등록·수정·삭제·검색, 품목 줄에서 바로 입고·수량 입력, 마감 재고 → 사용량 계산, 부족 경고, 부족 품목 발주 목록 → 거래처별 문자 복사 → 입고 완료 시 재고 자동 반영
3. 매출: 카드·현금 입력, 일별(14일)·주간(7일)·월별(6개월) 막대 그래프와 그 달 달력 전환, 포스기 형식 시간대별 매출과 그 달 시간대별 평균
4. 분쇄도 추천 + 샷 기록: 날씨(Open-Meteo) + 원두 숙성일 + 매장 샷 기록 보정, 시간별 예보로 조정 시점 알림, 샷 기록(등록·수정·삭제·검색)과 맛 평가(맛 지도)
5. 직원 권한·관리자: 관리자 비밀번호 해시(PBKDF2 60만 회) + 복구 코드, 직원별 권한 켜고 끄기, 설정은 관리자 전용
6. 고객: 전화번호·이름·메모 검색, 누적 45,000원마다 무료 음료 쿠폰
7. 설정: 매장 시작 설정(그라인더·다이얼 방향), 매장 위치(현재 위치 + 지도 핀, 가장 가까운 읍·면·동 자동 입력), 분쇄도·추출 기준, 영업 시간, 백업 내보내기/불러오기

## 분쇄도 추천식
```
추천 = 기준값 + 방향 × ( − a×(습도−기준습도)/10 − b×(기온−기준기온)/10 + 숙성 보정 ) + 기록 보정
```
기본값: 기준 6.5 (라마르조꼬, 높을수록 가늘게), 습도 60%, 기온 20℃, a=0.2, b=0.1, 로스팅 3일 이내 −0.1, 결과는 6.0~7.0. 방향은 그라인더 다이얼이 '높을수록 굵게'면 부호를 뒤집습니다.
기록 보정은 같은 원두·같은 그라인더에서 목표 추출 시간(26~30초)과 목표 도징(±0.2g) 안에 든 "잘 나온 샷" 최근 10개의 (실제 분쇄도 − 그때 날씨 기준 추천값) 평균입니다 (±0.3 제한). 잘 나온 샷이 3개 미만이면 보정하지 않습니다.

## 페이지
| 경로 | 페이지 |
|---|---|
| `/` | 홈 (날씨, 오늘 할 일, 인수인계, 추천 분쇄도, 매출 요약) |
| `/ops` | 운영: 오늘(체크리스트·인수인계) / 재고 / 발주 탭 |
| `/grind` | 분쇄도 추천 + 샷 기록 |
| `/sales` | 매출 |
| `/customers` | 고객 |
| `/settings` | 설정 (관리자 전용) |
| `/setup` | 매장 시작 설정 |

## 기술
React 19, Vite, React Router, Context + useReducer, localStorage, Recharts, Open-Meteo API (키 없음), Leaflet 1.9.4 + OpenStreetMap 타일(매장 위치 지도)

## 실행
```bash
npm install
npm run dev
npm test        # 자동 테스트 52개 (Vitest + Testing Library)
npm run lint    # 코드 검사 (Oxlint)
```

GitHub Actions(`.github/workflows/test.yml`)가 main에 올릴 때와 PR마다 린트 → 테스트 → 빌드를 자동으로 실행합니다.
